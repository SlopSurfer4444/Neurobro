# Publication scope

This repository is a curated source-only snapshot with a new Git history. It contains the implementation and synthetic tests; it is not a backup of a live installation.

Included: Telegram gateway sources/tests/configuration examples, native Python/Node bridge sources and tests, Windows GUI launcher source, experimental Windows Rust crates and their paired contracts/fixtures, dependency manifests/lockfiles, and newly written explanatory documentation.

Excluded: original Git history and internal agent instructions; operational receipts and development journals; real group messages, participant lists and media; account/session credentials; encrypted runtime stores; installed executables, dependencies, compiled artifacts and the WSL disk image.

Some copied tests and reference sources originally contained machine-specific locations. Public-copy adaptations replace these with temporary directories, executable configuration or generic example paths. The original stopped installation is not modified or started by this publication.

No real Telegram screenshots are included. Synthetic fixture names, identifiers, tokens and tiny encoded test images are examples rather than production records. Pattern scans are supplemented with source review, but publication is not represented as a formal security certification.
