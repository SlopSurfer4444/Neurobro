# Нейробро

Экспериментальный участник Telegram-беседы: модель с контекстом, историей, инструментами и возможностью самой вступать в разговор.

Проект прошёл живое тестирование в группе. В ходе разработки пришлось решать не только «как получить ответ модели», но и как сохранить нить разговора, не отправить сообщение дважды после неопределённого сбоя, обработать ошибку генерации и корректно завершить процессы.

## Устройство репозитория

- [Архитектура](docs/architecture.md): Telegram → TypeScript/Node → Python в WSL → внешний Codex App Server → облачная модель.
- [Заметки о разработке](docs/design-notes.md): принятые решения и ограничения.
- `packages/telegram-gateway/src`: основной шлюз, память, очередь, инструменты и жизненный цикл действий.
- `packages/telegram-gateway/test`: синтетические проверки, включая восстановление и отказы.
- `crates`: собственные экспериментальные Rust-компоненты Windows-изоляции. Сам Codex App Server — сторонняя разработка.

Разрабатывался с помощью AI-агентов и проверялся в живой беседе. Обратная связь участников влияла на приоритеты исправлений.

В публикации оставлены исходники и синтетические данные. Переписки участников, аккаунты, ключи, журналы эксплуатации и образ WSL исключены. Старая история Git не переносилась.

Офлайн-проверки и границы воспроизводимости описаны в [основном README](README.md). Это исходники экспериментальной системы; полностью переносимый установщик, безошибочная инициатива и гарантированная круглосуточная работа не заявляются.
